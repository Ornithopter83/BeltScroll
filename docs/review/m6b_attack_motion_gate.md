# M6B Attack 1~3 시간 기반 동작 검수 게이트

## 검수판과 격리 재생

`assets/art/review/m6b_attack_motion_strip.png`는 아래 여섯 원본 PNG를 사용한 1920×1080 비교 스트립입니다. 각 프레임은 1254×1254 원본 캔버스 전체를 보여 주며, 노란 십자는 alpha 기준 최하단 접점, 민트 표식은 별도로 지정한 임시 지지발 후보입니다. 재생 도구는 RESOURCE 시트, Player 장면, 애니메이션 manifest 또는 원본 PNG를 읽어 수정하지 않습니다. 검수판은 기존 PNG 원화만 직접 읽습니다.

Godot 창으로 실행합니다.

```powershell
godot --path . --script res://tools/build_m6b_attack_motion_review.gd
godot --headless --path . --script res://tests/m6b_attack_motion_review_smoke.gd
```

도구는 정지 비교판을 보여준 뒤 큰 재생 영역에서 실제 후보 텍스처를 순서대로 교체합니다. 보간이나 새 중간 프레임은 만들지 않습니다. 각 포즈는 표의 목표 시간만큼 유지하며, `RenderingServer.frame_post_draw` 완료 횟수와 시작부터 종료까지의 실측 시간(ms), 렌더 프레임 수를 기록합니다. 스트립 PNG는 정지 비교 자료이고 실제 재생 시간은 창 실행 로그에 남습니다. Attack 1·2 접촉은 각각 120ms, Attack 3 접촉은 140ms입니다. 이 게이트에는 실행 창의 실측 노출 로그가 아직 없습니다. 도구를 실행하면 조건별 로그가 생성됩니다.

## 선택한 원화 순서와 승인 상태

| 공격 | 순서 | 원화 PNG | 목표 유지 시간 | 기존 상태 |
|---|---|---|---:|---|
| 1 | 준비 | `elven_fighter_attack1_startup_v1_safe_candidate_1254x1254.png` | 105ms | 후보; startup safe 게이트상 시각 승인 대기 |
| 1 | 접촉 | `elven_fighter_attack1_reference_v1_contour_candidate_1254x1254.png` | 120ms | 기존 게이트는 contour 접촉을 승인으로 기록; 이번 작업은 상태를 바꾸지 않음 |
| 2 | 중간 | `elven_fighter_attack2_inbetween_v1_safe_candidate_1254x1254.png` | 90ms | 후보; 시각 승인 대기 |
| 2 | 접촉 | `elven_fighter_attack2_contact_v6_safe_candidate_1254x1254.png` | 120ms | safe 정규화 후보; 시각 승인 대기 |
| 3 | 준비 | `elven_fighter_attack3_startup_v1_safe_candidate_1254x1254.png` | 105ms | 후보; 시각 승인 대기 |
| 3 | 접촉 | `elven_fighter_attack3_reference_v2_safe_1254x1254.png` | 140ms | 후보; 시각 승인 대기 |

확보된 attack2 후보에는 시작 포즈가 없습니다. 그래서 attack2는 중간에서 시작해 접촉으로 이어집니다. 시퀀스를 풍성하게 보이도록 같은 이미지를 한 번 더 넣지 않습니다. 동일 PNG가 프레임 목록에 중복되면 빌더가 거부합니다. 서로 다른 파일이라는 이유만으로 새로운 동작 원화로 인정하지 않으며, alpha 실루엣 변화 수치와 시각적 프레임 검수는 별도로 봅니다.

## 시각 검수 항목

- **손·팔 실루엣:** attack1은 가드 주먹에서 수평으로 뻗는 앞팔로, attack2는 앞으로 뻗은 팔과 접힌 반대 팔을 유지하면서 몸통·뒤팔 위치가 바뀌는 포즈로, attack3은 양손 가드에서 위로 뻗는 주먹으로 이어집니다. 손 모양, 손목 각도, 전완 윤곽, 팔꿈치 굽힘, 어깨 연결과 빠른 재생의 프레임 팝을 확인합니다.
- **정체성:** 후보들에는 뾰족한 귀, 갈색 포니테일, 청록색 의상, 금색 장식, 장갑과 부츠가 이어집니다. 얼굴, 의상 주름, 비율과 렌더링 세부는 원화 생성 판본 사이에 차이가 있습니다. 도구는 정체성 일치를 승인하지 않습니다. 각 공격 쌍을 승인된 기준 포즈와 대조해 사람이 결정합니다.
- **발 접지:** 노란 표식은 최하단 alpha 행 중심이고, 민트 표식은 별도 수동 지정 지지발 후보입니다. 같은 값이 아니며 포즈 사이에 부츠 선택이 바뀔 수 있습니다. 알파 최하단점만으로 실제 지지발이나 미끄러짐을 판정할 수 없으므로, 의도한 지지 부츠·골반 이동·바닥 접촉을 재생 중 확인합니다.
- **접촉 시간:** 접촉 포즈 목표 유지 시간은 attack1 120ms, attack2 120ms, attack3 140ms입니다. 창 로그는 실제 경과 시간과 완료 렌더 프레임을 기록합니다. 이는 검수 미리보기의 노출 구간을 확인하는 값이며, 게임 히트박스나 전투 이벤트 시점을 뜻하지 않습니다.

## 판정 및 승인 기록

| 검수 내용 | 자동 기록 | 승인 상태 |
|---|---|---|
| 원화 중복 및 실루엣 변화 | PNG SHA-256으로 동일 파일 중복 거부; 공격별 alpha 실루엣 변화량 출력 | 동작 품질 승인 아님 |
| 손·팔 윤곽, 프레임 팝 | 원화를 순서대로 보간 없이 재생 | 사람의 시각 판정 대기 |
| 캐릭터 정체성 | 원화와 주요 시각 특징을 비교할 검수판 제공 | 사람의 시각 판정 대기 |
| 지지발·미끄러짐 | 최하단 alpha점과 임시 지지발점을 별도 표시 | 사람의 접지 판정 대기 |
| 접촉 유지 시간 | 목표 ms 및 실제 경과 시간·렌더 횟수 로그 | 목표 시간 지정; 실측 로그 미기록 |
| 본편 연결 | manifest·Player 연결을 수행하지 않음 | 런타임 미등록 |

이 자료와 smoke는 검수 보조물이며 후보 승격이나 기존 승인 상태 변경이 아닙니다. 승인 대기 포즈는 원화, 유지 시간, 기준점을 특정해 별도 판정이 기록될 때까지 격리합니다.
