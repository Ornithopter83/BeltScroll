# 3타 startup 연결 원화 검수 게이트

## 상태와 산출물

신규 startup 후보 `assets/art/player/elven_fighter_attack3_startup_v1_candidate_1254x1254.png`가 확인됐습니다. PNG를 원본 수정 없이 읽어 규격을 검사했으며, 포맷은 RGBA8, 캔버스는 1254×1254입니다. 비영점 alpha 경계 여백은 좌/상/우/하 **0/19/10/17px**이고 왼쪽 가장자리에 불투명 픽셀이 있어 외곽 완전 투명 조건도 실패합니다. 따라서 90px 안전 여백 및 완전 투명 외곽 기계 게이트 **실패**입니다. 검수판에는 원본을 그대로 포함해 실패 상태를 표시했습니다.

`assets/art/review/player_attack3_startup_comparison.png`는 다음 네 패널을 192px 게임 표시 높이의 3배인 576px로 같은 발 기준선에 맞춰 보여줍니다.

1. 승인 정지 원화 v8 clean
2. 2타 접촉 v6 safe 후보
3. 신규 3타 startup 후보
4. 기존 3타 접촉 v2 clean 후보

비교 시 alpha 5% 이상 픽셀의 경계를 표시 영역 계산에 사용합니다. 안전 규격은 별도로 alpha > 0인 전체 실루엣으로 검사하므로 희미한 alpha 픽셀도 여백/외곽 판정에 포함됩니다. 비교용 확대와 발 기준선 정렬은 원본 파일을 바꾸지 않습니다.

2타 v6 safe와 startup 모두 사람의 시각 검수/승인이 완료됐다는 기록이 없습니다. v8만 기존 승인 정지 원화입니다. 이 게이트는 원화를 본편 Player, 애니메이션, 런타임 리소스에 연결하지 않습니다. 기계 규격 통과 여부와 사람의 시각 승인 상태는 독립된 결정입니다.

## 연결 연속성에 대한 시각 관찰

아래 내용은 검수판에서 보이는 형태에 대한 관찰과 검수 질문입니다. 얼굴·의상·동작의 승인 결과가 아닙니다.

- **얼굴과 귀:** v8, startup, 기존 3타 접촉에서 오른쪽을 향하는 얼굴과 뾰족한 귀가 읽힙니다. startup의 눈·코 위치, 귀의 머리 부착점/크기, 머리 기울기가 직전 2타 접촉에서 위로 올리는 3타 접촉까지 자연스럽게 이어지는지 확인이 필요합니다.
- **의상:** startup은 청록 상의와 금색 테두리, 허리 장식, 긴 바지와 부츠의 어휘를 유지합니다. 2타 safe 접촉에서 크게 흔들리는 허리천과 몸통의 회전에 이어 startup의 옷자락·주름이 관성상 연결되는지, 기존 3타 접촉의 상체/허리 장식으로 튀지 않고 이어지는지 검토해야 합니다.
- **주먹 동선:** 2타 접촉은 화면 오른쪽으로 뻗은 주먹, startup은 몸 앞쪽으로 당겨진 주먹/가드, 기존 3타 접촉은 머리 위로 올라간 주먹으로 보입니다. 회수 후 어퍼컷을 올리는 경로가 읽히는지, 팔꿈치 굽힘과 어깨 관절이 프레임 사이에서 끊기지 않는지 확인해야 합니다.
- **무게중심:** startup은 무릎을 굽힌 낮은 준비 자세로 보이고 기존 3타 접촉은 몸통과 공격 팔이 위쪽으로 뻗습니다. 골반/흉곽이 위로 상승하는 동안 균형이 유지되는지, 2타의 회전과 3타의 상승 사이에 급격한 중심 이동이 없는지 확인해야 합니다.
- **지지발:** 발 최하단을 공통선에 맞춘 비교는 바닥 접촉의 위치를 빠르게 비교하기 위한 표시입니다. 실제 지지발은 자동 판별하지 않습니다. startup에서 어느 발이 지면을 딛는지, 2타 접촉에서 회수해 상승할 때 해당 발의 접지가 유지되는지, 발 교대가 의도된 동작인지 확인해야 합니다.
- **포니테일:** 세 포즈에서 높은 묶음과 긴 갈색 꼬리가 유지됩니다. 묶음 위치를 기준으로 꼬리의 끝점/부피가 2타 회전에서 startup 준비 자세를 거쳐 3타 상승 시점까지 단계적으로 이동하는지 확인해야 합니다.
