# M5B 실제 원화 통합 검수판 및 시각 결정 게이트

[통합 검수판 PNG](../../assets/art/review/m5_art_approval_board.png)는 1254×1254 원본 캔버스 전체를 576×576으로 동일 배율 표시합니다. 이는 게임 표시 높이 192px의 3배입니다. 체커보드 위에서 얼굴·의상 identity와 실루엣을 비교하고, 모든 패널을 우향 기준으로 놓았습니다. 좌향 적용은 `flip_h` 한 번이며 원화 자체에 미러를 중복 적용하지 않습니다.

노랑 십자는 alpha 5% 이상인 가장 낮은 픽셀 행의 중앙입니다. 이는 기계적으로 구한 **alpha anchor**이며 실제 접지점을 판정하지 않습니다. 민트 마름모는 기존 모션 검수에서 별도로 제안한 **지지발 후보**입니다. 두 값이 다르거나 민트 표식이 없을 때 alpha anchor를 지지발로 간주하지 않습니다. 민트 후보가 제공되지 않은 포즈는 임의 좌표를 만들지 않고 `NOT SET`으로 표시했습니다. 빨강 글자는 해당 원화의 주먹 방향 또는 모션 검수 메모입니다.

## 원화별 결정 기록

현재 run 원화 파일이 확인되어 패널에 포함했습니다. 생성기는 `assets/art/player`에서 이름에 `run`과 `candidate`가 함께 있고 PNG 파일이 실제 존재하는 경우에만 후보를 추가합니다. 해당 파일이 없으면 run 원화 이미지를 만들지 않고 `RUN / NOT PROVIDED` 칸으로 미확보 상태를 표시합니다.

## 시각 결정 체크리스트

- **Identity:** 각 원화의 얼굴선, 귀, 눈, 포니테일/머리 장식, 청록 의상, 금색 장식, 장갑과 부츠를 v8 기준과 나란히 봅니다. 기계 규격 통과는 외형 보존 판정이 아닙니다.
- **좌우 방향:** 원본 우향에서 좌향으로 `flip_h` 한 번만 적용했을 때 주먹이 진행 방향을 향하고 얼굴/장식과 비대칭 실루엣이 읽히는지 봅니다.
- **주먹 동선:** 1타는 직선 전방, 2타 접촉은 백피스트 스윕, 3타는 위쪽 접촉으로 표시했습니다. startup·중간 후보는 다음 접촉 포즈로 이어지는 손 위치와 팔/몸통의 회전을 사람이 확인해야 합니다.
- **발과 alpha anchor:** 노란 alpha anchor 변화만으로 미끄러짐을 단정하지 않습니다. 민트 지지발 후보와 각각 비교하고, 어느 발이 실제 체중을 받는지는 검수자가 결정합니다. 기존 후보 동선 검수에서 v6 safe→3타 접촉 alpha anchor는 x=1099→273으로 바뀌었으며, 이는 지지발 이동을 증명하지 않습니다.
- **3배 표시와 잘림:** 모든 비교는 원본 캔버스 전체를 3배 동일 높이로 표시합니다. safe 후보는 포즈별로 원본보다 작아졌을 수 있으므로 상대 캐릭터 크기와 각 패널의 안전 여백도 확인합니다.
- **별도 판정:** 기계 규격, 동작 연속성, 사람 승인은 표의 서로 다른 열로 기록합니다. PNG 생성 성공, safe 검사 통과, smoke 통과 또는 검수판 생성은 승인 상태를 바꾸지 않습니다.

## 재생성 및 smoke

```powershell
godot --headless --path . --script res://tools/build_m5_art_review_board.gd
godot --headless --path . --script res://tests/m5_art_review_board_smoke.gd
```

`tools/build_m5_art_review_board.gd`는 비교 PNG만 만들고 animation manifest나 원본 원화를 수정하지 않습니다. 승인 접촉은 기존 `data/art/animation_manifest.json`과 프레임 레지스트리 게이트에 명시된 세 장을 기존 승인으로 표시하며, 나머지 startup·safe contact·중간·run 원화는 미승인 후보로 남깁니다.
