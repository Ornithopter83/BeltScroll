# 2타 safe 중간 · v6 safe 접촉 연속 모션 검수 게이트

## 검수 산출물과 범위

`assets/art/review/player_attack2_candidate_motion_strip.png`는 실제 1920×1080 Godot Window 및 같은 크기의 Window Viewport를 확인한 뒤 실행한 격리 전투 미리보기 캡처입니다. 화면에는 Forest Ruins 배경을 두고 우향·좌향 각 4개의 연속 전환을 재생해 모든 포즈를 남겼습니다. 좌향은 원화의 수평 반전만 적용했습니다. 각 프레임은 alpha 5% 실루엣 높이를 330 표시 px로 균일 조정하고 최하단 alpha 행 중심을 공통 바닥선에 놓았습니다. 노란 수직선은 실제 재생에 사용한 이미지의 하단 alpha anchor입니다.

| 순서 | 원화 | 상태 | 재생 기준 시간 |
|---|---|---|---:|
| 1 | `elven_fighter_attack1_reference_v1_contour_candidate_1254x1254.png` | 승인 접촉 | 105 ms |
| 2 | `elven_fighter_attack2_inbetween_v1_safe_candidate_1254x1254.png` | safe 중간 후보 | 50 ms |
| 3 | `elven_fighter_attack2_contact_v6_safe_candidate_1254x1254.png` | v6 safe 접촉 후보 | 120 ms |
| 4 | `elven_fighter_attack3_reference_v2_contour_candidate_1254x1254.png` | 기존 승인 접촉 | 140 ms |

위 재생 기준은 기존 프레임 길이를 재현하기 위한 검수 입력입니다. 전체 목표는 방향당 415 ms, 양 방향 총 830 ms입니다. Windows 실측에서는 8개 구간이 각 61–125 ms로 표시되어 목표보다 최대 약 19 ms 길었습니다. 이는 실제 Window의 프레임 단위 샘플링 지연이며 재생 시간 측정에 포함했습니다. 중간 샘플 시각은 각 구간 목표의 절반입니다. 전체 실행은 약 0.99초였습니다.

재현 명령:

```powershell
godot.exe --path . --script res://tools/capture_attack2_candidate_motion_review.gd
godot.exe --headless --path . --script res://tests/attack2_candidate_motion_review_smoke.gd
```

## 비교 관찰과 남은 판단

- **텍스처와 얼굴 identity:** 1타, safe 중간, v6 safe 접촉에서 갈색 포니테일·금색 머리 장식·뾰족한 귀·청록색 의상·갈색 장갑과 부츠가 이어집니다. 중간은 등과 어깨가 더 드러나는 3/4 뒤돌림이고, v6 접촉은 같은 방향에서 주먹을 뻗습니다. 3타는 같은 의상/머리 색 계열로 읽히지만 얼굴과 시선이 위쪽으로 회전합니다. 얼굴의 세부 일치와 공격 중 회전의 자연스러움은 담당자의 시각 승인이 필요합니다.
- **시간 전환:** 각 원화를 실제로 설정하고 다음 원화로 넘어가기 전 지정 시간을 기다렸습니다. 50ms 중간 후보는 가장 짧아 한두 Window 프레임으로 보일 수 있습니다. 현재 입력은 자동으로 중간 동작을 생성하지 않으므로 1타 접촉에서 중간으로 들어갈 때 팔/몸통의 큰 포즈 변화가 남습니다. 빠른 재생에서 팝처럼 보이는지 사용자 확인이 필요합니다.
- **발 anchor와 지지발:** 실제 1254px 원화의 하단 alpha anchor는 각각 1타 `(1073,1122)`, 중간 `(1064,1161)`, v6 접촉 `(1100,1143)`, 3타 `(274,1145)`입니다. 첫 세 포즈는 오른쪽 하단 부츠에 anchor가 놓이고 3타에서 왼쪽 하단 부츠로 바뀝니다. 330px 표시에 정렬하면 v6에서 3타로 anchor가 약 217px 반대편으로 옮겨집니다. 이 값은 하단 픽셀 접점의 자동 측정이며 체중을 받는 지지발을 뜻하지 않습니다. 두 부츠는 비교판에서 바닥에 닿아 보이지만, 3타 전환 때 지지발이 실제로 바뀌는지와 접지가 자연스러운지 시각 확인이 필요합니다. 단일 공통 pivot이 이 전환을 상쇄하지 않도록 anchor 또는 발별 접지 기준을 개선해야 합니다.
- **회전과 방향:** 좌향은 우향 포즈를 `flip_h`로 반전한 검수입니다. 좌우 모두 캔버스 잘림 없이 표시됩니다. 공격 단계에서 몸통의 뒤돌림에서 위쪽 주먹 자세로 넘어가는 회전은 원화 사이 보간 없이 순간 전환됩니다.
- **표시 크기/texture:** 실루엣 높이를 통일해 프레임 간 외형 크기 변화는 비교판에서 정규화했습니다. 실제 원화의 표시 크기와 픽셀 디테일 차이는 본편 스케일로 적용 전 별도 확인이 필요합니다.

## 승인 상태

이 검수는 기본 manifest, 본편 Player, 런타임 애니메이션 또는 본편 승인 목록을 수정하거나 후보를 등록하지 않았습니다. 중간 safe와 v6 safe 접촉은 여전히 후보이며, 사용자 시각 승인이 없어 본편 승인으로 승격하지 않습니다. 지지발/anchor 급변, 50ms 중간의 가독성, 회전 및 얼굴 identity를 시각 검토한 뒤 개선 또는 승인을 결정해야 합니다. 자동 smoke는 창 캡처 크기·원화 입력·anchor 표식과 하단 anchor 이동을 확인할 뿐 동작이나 미술 승인을 대신하지 않습니다.
