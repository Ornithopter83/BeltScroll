# Player v9 판타지 원화 검수 게이트

## 범위와 상태

- 비교 기준은 현재 `scenes/player/player.tscn`이 참조하는 v8 정리 후보(`elven_fighter_reference_v8_clean_candidate_1254x1254.png`)다.
- 검수 후보는 확보된 `elven_fighter_reference_v9_fantasy_1254x1254.png`다.
- 검수판: `assets/art/review/player_v9_comparison.png`.
- v9는 검수 전용이다. 플레이어 장면 참조, 원본 파일, 애니메이션 자산은 변경하지 않았다. 승인 상태는 미승인이다.

## 파일·알파·안전 여백

두 입력 모두 PNG 시그니처가 유효하고 Godot에서 1254×1254 RGBA8로 읽혔다. 알파 채널에 투명 영역과 불투명 실루엣이 모두 있다. 안전 여백 기준은 네 변 각각 90px 이상이다.

| 입력 | 알파 경계 (x, y, w, h) | 좌·상·우·하 여백 | 알파 픽셀 비율 | 90px 기준 |
|---|---:|---:|---:|---|
| 현재 v8 후보 | (110, 90, 1034, 1074) | 110 / 90 / 110 / 90px | 17.07% | 통과 |
| v9 판타지 | (0, 9, 1248, 1245) | 0 / 9 / 6 / 0px | 24.95% | 실패 |

v9 실루엣은 좌·우·하단 캔버스 경계에 닿는다. 이 검수판은 원화를 자동 정규화하거나 자르지 않고 원래 경계를 보존한다. 게임 표시 변환이나 애니메이션 정렬 전에 투명 여백과 캔버스 내 실루엣 크기를 수정할 필요가 있다.

## 화면 크기와 anchor 비교

현재 게임의 viewport는 1920×1080, 플레이어 스프라이트 배율은 0.4469274, 카메라 줌은 1.2다. 알파 기준 v8 실루엣은 화면에서 약 576px 높이고 v9는 같은 배율을 적용하면 약 668px 높다. 비교판 위쪽과 Forest Ruins viewport는 동일한 원본 픽셀 배율과 발 기준선을 적용해 이 크기 차이를 보존한다. 화면 좌우에 후보를 나눠 배치했다.

아래 4쌍은 얼굴·귀, 장갑/손목, 의상 몸통·허리, 양발/부츠 순이다. 각 crop은 게임 스프라이트 배율의 3배(원본 픽셀당 약 1.609 화면 비교 픽셀)로 확대한 뒤 한 장의 검수판에 담도록 구획 안에 맞춰 표시한다. 청록색 구분선은 v8, 금색 구분선은 v9다.

시각상 v9는 갈색 포니테일, 엘프 귀, 청록 의상, 금색 장식, 갈색 손목 보호구와 부츠 등 주요 모티프를 유지한다. 다만 v8의 두 주먹을 든 가드 자세와 달리 v9는 한 손을 펴서 뻗고 다른 손은 몸 앞에 둔 자세다. v9 의상은 교차형 짧은 상의와 노출된 복부, 넓고 낮은 자세를 보여 주며 v8의 높은 목선 상의와 실루엣에 비해 체형·복식 인상이 크게 달라진다. 얼굴 표현도 더 사실적인 하이 판타지 미인형으로 이동했다.

이 차이가 기존 플레이어 identity에 부합하는지는 자동 검사로 승인하지 않는다. 담당자가 얼굴 인상, 귀와 헤어 형태, 손/가드 실루엣, 의상 인상과 기존 동작 자산의 연속성을 검토한 뒤 결정해야 한다. 현재 판단은 **사람의 시각 검토 필요 · 교체 미승인**이다.

## 재생성 및 smoke 검사

비교판 재생성:

```powershell
godot --headless --path . --script res://tools/build_player_v9_comparison.gd
```

전용 검수 smoke:

```powershell
godot --headless --path . --script res://tests/player_v9_art_review_smoke.gd
```

smoke는 PNG 규격과 alpha 경계/여백을 확인하고, 기준 여백 미달을 통과로 숨기지 않는지, 결과 PNG가 있으며 플레이어 장면이 계속 v8을 참조하는지 검사한다.
