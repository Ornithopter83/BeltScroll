# Player run v5 anti-phase 검토 게이트

## 현재 판정

**미수용 / 다리 교대 미입증 / 사람 승인 전 본편 미등록**

원본은 `assets/art/player/elven_fighter_run_stride_v5_far_leg_forward_candidate_1254x1254.png`에 있다. 과거 검수 도구가 다른 파일명(`...run_stride_v5_candidate...`)만 찾으면서 원본을 놓쳤다. 원본 SHA-256은 `310F7A6F95B0966247754986095042D275839891B80C73C187383B35D920F6E2`, 크기는 1,186,277바이트다. safe 산출물은 원본과 별도 경로에 만들며 원본은 덮어쓰지 않는다. 실제 비교에서 v1과 v5가 같은 접촉 보폭으로 보여 다리 역할 교대가 입증되지 않았다. 따라서 v5는 미수용으로 유지한다.

## 비교 산출물과 축척

`assets/art/review/player_run_v5_antiphase_comparison.png`는 v1 safe와 v5 safe를 같은 크기로 보여준다. 각 표시는 원래 1254×1254 전체 캔버스를 종횡비 변경 없이 192×192로 축소한 것이다(배율 192/1254, 약 0.15311). 첫 행은 오른쪽 방향, 둘째 행은 좌우 반전 방향이며, 왼쪽 열은 v1 safe, 오른쪽 열은 v5 safe다.

v1 safe에서 확인 가능한 보폭은 가까운 다리가 화면 오른쪽 전방으로 뻗고 먼 다리는 화면 왼쪽 뒤로 접혀 있는 자세다. 상체와 골반은 진행 방향으로 기울며 팔은 다리와 반대 방향으로 흔들리고, 포니테일은 뒤쪽 왼편으로 흐른다. 전방 부츠는 오른쪽 아래, 후방 부츠는 왼쪽 아래에 있다. 이 관찰은 v1 모습만 기록하며 v5와의 차이를 뜻하지 않는다.

생성된 192px 비교에서 v5도 가까운 다리/부츠가 골반 오른쪽 전방에 있고 먼 다리/부츠가 왼쪽 후방에 남아 있다. 요청된 가까운 다리 후방·먼 다리 전방 교대는 보이지 않는다. 골반 기울기와 팔의 카운터 스윙은 v1과 같은 방향이며 포니테일도 뒤쪽 왼편으로 흐른다. 양쪽 부츠가 좌우로 분리된 점은 보이지만 다리 교차/역할 교대는 확인되지 않는다. 좌우 미러 행에서도 같은 source pose를 반전한 결과라 별도 보폭 증거가 아니다.

동일 Window 캡처 위상 0에서 v1 alpha 높이는 193.80px, v5는 190.92px로 v5가 2.88px 작게 표시됐다. 192px 전체 캔버스 배율은 고정되어 있어 이는 두 원화의 alpha 실루엣 크기 차이다. source에서 지정한 발 후보점은 v1 `(1090,1200)`, v5 `(1145,1205)`이며, 같은 위상 캡처에서 골반 근사점부터 후보점까지의 수평 거리는 각각 74.6px과 85.2px, 수직 거리는 68.5px과 64.6px이었다. 이 점들은 서로 다른 원화에서 선택한 시각 후보일 뿐 실제 지지발/접지 판정이 아니다. 따라서 anchor 차이는 기록하되 수용 근거로 사용하지 않는다.

실제 Window 측정에서 실루엣 높이는 190.36–193.98px, 인접 높이 변화 최대 3.34px, 발 anchor 후보 수직 변화 최대 7.78px였다. 측정 가능한 수치가 있어도 이미지가 같은 접촉 보폭으로 보이고 어느 발이 지지발인지 확정되지 않았으므로 다리 교대 증거로 볼 수 없다. 전체 캔버스 표시 크기는 고정하며 실제 alpha bounds와 골반·부츠·발 anchor 차이는 사람이 갤러리와 캡처에서 판정해야 한다.

## 필수 반대 보폭 판정

수용하려면 원화에서 v1의 **가까운 다리 전방 / 먼 다리 후방**과 반대로 v5의 **가까운 다리 후방 / 먼 다리 전방**이 분명하게 읽혀야 한다. 다리의 교차와 원근 관계를 확실히 구분할 수 없으면 v5도 미수용이다. 좌우 반전이나 포즈 전체 위치 변경만으로는 다리 역할 교대를 증명하지 않는다.

v5 원화가 추가되면 도구가 원본 파일을 덮어쓰지 않고 입력 SHA-256 및 바이트 수를 출력한 뒤 별도 `elven_fighter_run_stride_v5_safe_candidate_1254x1254.png`를 생성한다. safe는 1254×1254 RGBA8이며 alpha artwork 경계 기준 사방 90px 이상 여백과 고립 alpha 픽셀 0개를 검사한다. 이후 동일한 전체 캔버스 192px 배율로 좌우 방향 비교를 갱신한다.

사람 검토 때 다음 항목을 모두 기록한다.

- 가까운 다리와 먼 다리의 전후 위치 및 역할이 실제로 교대했는지
- 골반의 위치, 기울기, 다리 연결부가 새 보폭과 맞는지
- 팔 swing 방향과 진폭
- 양쪽 부츠의 전후 위치와 지면 접촉 인상
- 포니테일의 흐름과 진행 방향 관계
- 전체 캔버스 축척, alpha 경계 크기, 기준점 및 양쪽 발 anchor 이동

이 작업은 원화 후보와 검토 산출물만 다룬다. v5를 본편, animation resource, manifest 또는 allowlist에 등록하지 않는다. 위 항목 검토 후에도 수용은 사람 승인에 달려 있다.
