## 산출물과 처리

- 원본: `assets/art/player/elven_fighter_run_stride_v1_candidate_1254x1254.png`
- 별도 후보: `assets/art/player/elven_fighter_run_stride_v1_safe_candidate_1254x1254.png`
- 3배 비교판: `assets/art/review/player_run_stride_v1_safe_comparison.png`
- 재현 도구: `tools/prepare_player_run_stride_safe.gd`
- smoke 검증: `tests/player_run_stride_safe_smoke.gd`

원본은 1254×1254 RGBA8이다. 원본 비영점 alpha 경계는 `(x=25, y=19, w=1213, h=1211)`이며 좌/상/우/하 여백은 25/19/16/24px다. safe 제작은 고립 alpha 픽셀을 제거한 실루엣 경계를 기준으로 비율 고정 축소했다. 목표 콘텐츠 한도 1050×1050에 Lanczos 리샘플링 여유를 더해 실제 리사이즈 크기는 1034×1050, 균일 배율은 0.867052다. 축소는 premultiplied alpha에서 수행한 뒤 unpremultiply하고, 완전 투명 픽셀의 RGB를 0으로 정리했다.

safe PNG도 1254×1254 RGBA8이다. 비영점 alpha 경계는 `(110, 102, 1012, 1048)`이며 좌/상/우/하 여백은 **110/102/132/104px**다. 바깥 네 변은 완전 투명하고 고립 alpha 픽셀은 0개다. 정리 과정에서 원본의 고립 alpha 픽셀 379개와 리샘플링 후 고립 픽셀 114개를 제거했다. smoke에서 얼굴·귀, 양쪽 장갑, 양쪽 부츠, 옷자락 구역의 alpha 잔존을 확인했다.

## 3배 비교 관찰

비교판은 v8 정지 포즈 → v1 run 원본 → v1 run safe 순서다. 각 프레임을 576×576으로 표시해 192×192 게임 캔버스 기준 3배 크기로 비교한다. 노란 십자 표시는 각 프레임에서 alpha 5% 이상인 최하단 접지 후보를 뜻한다.

| 항목 | v8 정지 | v1 원본 | v1 safe |
|---|---:|---:|---:|
| alpha 5% 경계 크기 | 754×1115px | 1024×1060px | 888×920px |
| 경계 종횡비 (폭/높이) | 0.67623 | 0.96604 | 0.96522 |
| v8 대비 경계 높이 | 100% | 95.07% | 82.51% |
| 최하단 접지 후보 (x,y) | (993,1194) | (1106,1165) | (1032,1096) |

정지 포즈는 상체를 세우고 양발로 받치는 가드 자세다. run v1은 상체를 앞으로 기울이고 옷자락과 머리카락이 뒤로 뻗은 낮고 넓은 달리기 자세다. 원본은 폭이 v8보다 크게 보이지만 경계 높이는 약 95%다. safe는 캔버스 내 캐릭터 크기를 원본보다 균일하게 줄여 v8보다 작게 보인다. 실루엣 경계 종횡비는 축소 전후 약 0.00082 차이로 체형 비율을 유지한다. 얼굴, 귀, 장갑, 두 부츠와 옷자락은 smoke 구역 검사에서 계속 검출됐다.

달리기 자세의 접지 후보는 화면 오른쪽으로 뻗은 앞발이다. alpha anchor는 원본 `(1106,1165)`에서 safe `(1032,1096)`으로 이동해 **(-74,-69)px**다. 이는 균일 축소와 캔버스 중앙 재배치에 따른 이동이며, safe의 접지 후보는 v8의 정지 접지점보다 39px 오른쪽·98px 위다. 실제 플레이에서의 발 접촉과 애니메이션 연결은 이 정적 비교만으로 승인되지 않는다.
