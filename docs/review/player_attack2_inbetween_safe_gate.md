# 2타 중간 safe 후보 검수 게이트

## 판정 상태

`assets/art/player/elven_fighter_attack2_inbetween_v1_safe_candidate_1254x1254.png`를 별도 검수 후보로 만들었습니다. 원본 `elven_fighter_attack2_inbetween_v1_candidate_1254x1254.png`는 바이트 단위로 보존했습니다. 이 후보는 시각 승인 전이며 본편 장면·애니메이션·리소스에는 연결하지 않았습니다.

자동 스모크는 통과했지만 시각 승인으로 보지 않습니다. 얼굴과 복장, 포니테일, 양발이 보존되고 실루엣이 자연스러운지는 담당자의 별도 확인이 필요합니다.

## 후보 제작 방식과 검증 수치

- 원본 캔버스와 출력 캔버스는 모두 1254×1254 RGBA8입니다.
- 원본의 alpha 5% 이상 실루엣은 `(x=152, y=58, w=999, h=1135)`이며, 여백은 좌 152px·상 58px·우 103px·하 61px입니다. 요청된 90px 기준에 상단 32px, 하단 29px 부족합니다.
- 원본의 alpha 비영점 경계는 `(x=0, y=35, w=1236, h=1195)`까지 번져 있었습니다. 주 실루엣(alpha 5% 이상)에서 2px 넘게 떨어진 고립 alpha 조각 15,521개를 제거했습니다. alpha가 있는 원본 바깥 테두리도 검사하며 1/255 이하 오염만 투명하게 지웁니다.
- 주 실루엣을 비율 그대로 Lanczos 축소하고, premultiplied alpha로 색을 보간해 투명 RGB에서 생기는 가장자리 색 번짐을 줄였습니다. 내부 색·얼굴·의상·포즈를 다시 그리지 않았습니다.
- 출력의 alpha 비영점 여백은 좌 154px·상 90px·우 154px·하 90px입니다. 최외곽 1px 테두리에는 alpha 비영점 픽셀이 없습니다.
- alpha 5% 이상 실루엣 크기는 원본 대비 가로 `999→942px`(축소율 0.943), 세로 `1135→1070px`(축소율 0.943)입니다. 가로·세로 축소율 차이는 0.03%p 미만으로 비율 왜곡이 없습니다.
- alpha 5% 기준 발 anchor의 실루엣 내부 가로 위치 비율은 원본 0.9639, 후보 0.9639입니다. 캔버스 내 발 하단 픽셀은 원본보다 약 29px 위로 이동했습니다. 런타임 바닥선에 맞출 경우 pivot 또는 수직 위치 보정이 필요합니다. 후보 자체는 게임에 연결하지 않았습니다.

## 실제 3배 게임 캔버스 비교

게임 높이 192px의 3배인 576×576 캔버스로 원본과 후보 전체를 Lanczos 리샘플하고, alpha 5% 이상 영역을 재측정했습니다.

| 프레임 | 576×576에서 실루엣 크기 | 발 anchor 상대 x |
| --- | ---: | ---: |
| 원본 | 459×522px | 0.9639 |
| safe 후보 | 434×492px | 0.9639 |

후보는 3배 표시에서 원본보다 가로 약 5.4%, 세로 약 5.7% 작게 보입니다. 전신·양발·포니테일은 모두 캔버스 안에 남고, 발 anchor의 상대 가로 위치는 유지됩니다. 표시 크기가 줄어드는 점과 약 13px(29px×576/1254)의 수직 기준선 차이를 실제 게임에서 확인해야 합니다. 이 비교 수치는 576px 텍스처 축소에 대한 자동 측정이며, 게임 장면의 시각 승인이나 실제 런타임 배치 확인은 아닙니다.

## 재현 및 자동 검사

```powershell
godot --headless --path . --script res://tools/prepare_player_attack2_inbetween_safe.gd
godot --headless --path . --script res://tests/player_attack2_inbetween_safe_smoke.gd
```

스모크는 PNG 디코딩·캔버스 형식·alpha 여백·투명 외곽·균일 축소율·발 anchor 위치와 원본 바이트 보존을 검사하고 3배 축소 측정치를 출력합니다. 얼굴, 복장, 머리카락, 발 형태의 시각 승인 및 게임 내 배치 확인은 자동 검사 범위에 포함되지 않습니다.
