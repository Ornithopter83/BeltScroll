# Run Stride v2 Safe 독립 후보 검토 게이트

## 상태와 범위

- v2 반대 보폭 원화를 보존하고 별도 safe 후보를 생성했다.
- 기계 검사: 통과 (`tests/player_run_stride_v2_safe_smoke.gd`).
- 사람의 시각 승인: 대기.
- 완성된 달리기 애니메이션 판정: 하지 않음. 정지 포즈 1장과 보폭 후보 2장만으로 사이클·전환·타이밍을 승인할 수 없다.
- 본편 Player 및 애니메이션 manifest 등록: 금지.

## 산출물과 제작 절차

- 입력 원화: `assets/art/player/elven_fighter_run_stride_v2_opposite_candidate_1254x1254.png` (읽기만 함)
- 새 safe 후보: `assets/art/player/elven_fighter_run_stride_v2_safe_candidate_1254x1254.png`
- 비교판: `assets/art/review/player_run_stride_pair_safe_comparison.png`
- 재현 도구: `tools/prepare_player_run_stride_v2_safe.gd`
- 검사: `tests/player_run_stride_v2_safe_smoke.gd`

도구는 원화의 alpha 고립 픽셀을 제거하고 연결된 alpha bounds에 맞춰 1050×1050 콘텐츠 한도 안으로 비율 고정 축소했다. 선택된 크기는 1050×1029, 균일 배율은 0.846774, 캔버스 오프셋은 (102,112)다. Lanczos 축소 전에 premultiplied alpha로 변환하고, 결과를 unpremultiply한 다음 완전 투명 픽셀의 RGB를 0으로 정리해 가장자리 색 번짐을 줄였다. 원화 SHA-256은 `1f4886b34d699455578ea81e50b58ca2381e164dbf6fb0a6937ae513af2ec696`이며 실행 전후 바이트가 같다.

출력은 **1254×1254 RGBA8**이다. 전체 비영점 alpha 경계는 `(102,112,1040,1017)`이며 L/T/R/B 여백은 **102/112/112/125px**다. 네 바깥 변은 모두 완전 투명하고, 출력 고립 alpha 픽셀은 0개다. 원화에서 355개, 축소 결과에서 90개의 고립 픽셀을 제거했다. 완전 투명 픽셀 RGB는 모두 0이다. 스모크는 얼굴·귀, 양쪽 장갑, 양쪽 부츠, 옷자락 구역의 alpha 잔존과 균일 축소를 확인했다.

## 같은 게임 표시 크기 비교

비교판의 v8 idle, v1 safe, v2 safe는 각각 1254×1254 전체 프레임을 **192×192 게임 스프라이트 캔버스**에 동일하게 맞춰 렌더링했다. 보드의 각 타일은 이 표시 크기의 3배(576×576)다. 경계 크기는 alpha 5% 이상 기준이며 표시 크기는 192/1254 비율로 환산했다.

| 프레임 | alpha 경계 (원본 px) | 192px 표시 경계 (약 px) | 하단 alpha anchor (192px 좌표) |
|---|---:|---:|---:|
| v8 idle | 754×1115 | 115.43×170.67 | (151.95,182.82) |
| v1 safe | 888×920 | 135.95×140.74 | (157.99,167.83) |
| v2 safe | 886×887 | 135.62×135.74 | (161.95,167.31) |

v1 safe 대비 v2 safe 콘텐츠 경계 차이는 표시 폭 **-0.31px**, 높이 **-5.05px**다. 하단 alpha anchor 차이는 표시 좌표에서 **(+3.97,-0.52)px**다. anchor는 alpha 5% 기준 최하단 행의 수평 구간 중심으로 계산한 참고값이지, 물리 접지를 판정하는 값은 아니다. 두 그림 모두 시각상 화면 오른쪽으로 뻗은 앞쪽 부츠가 가장 낮은 지지 후보이고, 뒤쪽 부츠는 발끝이 들린 후보로 보인다. 정적 원화만으로 실제 지면 접촉이나 발 미끄러짐을 확정하지 않는다.

v8 idle은 두 발을 벌린 가드 자세로, 경계 높이가 170.67px이다. 두 달리기 후보는 더 낮고 넓은 전경 기울기이며 v1 safe가 140.74px, v2 safe가 135.74px로 표시된다. 달리기 후보를 idle과 같은 192px 캔버스에 그린 결과 두 후보 모두 idle보다 작게 보인다.

## 시각 비교 관찰과 한계

- **얼굴·귀·의상 identity:** 두 run safe에서 오른쪽을 보는 얼굴, 뾰족한 귀, 갈색 포니테일, 청록색 상의와 금색 장식, 갈색 손목 보호대와 부츠가 유지된다. v8 idle과도 캐릭터 색·의상 계열이 이어진다. 크롭과 원화가 다른 포즈이므로 세부 장식의 완전 일치는 사람 검토가 필요하다.
- **양발 후보:** 두 run 포즈 모두 앞쪽(화면 오른쪽) 부츠가 바닥을 향해 길게 뻗고 최하단 alpha anchor가 놓인다. 뒤쪽(화면 왼쪽) 부츠는 뒤로 접혀 발끝이 올라가 있다. 실제 지지 후보는 앞쪽 발로 보이나 단일 프레임은 접촉/체공 시점을 증명하지 않는다.
- **골반 높이:** 비교판에서 두 safe의 벨트·골반은 낮고 전방 기울기 아래에 있으며, v2는 v1보다 하체 경계 높이가 표시 기준 약 5px 작다. 골반 landmark 좌표를 분할 측정하지 않았으므로 골반 관절 높이나 프레임 간 수직 팝은 판정하지 않았다.
- **포니테일 연결:** 두 후보 모두 포니테일이 머리 뒤쪽 금색 끈에 연결되어 보이고 뒤로 흐른다. 뿌리 연결은 정지 이미지 관찰이며 움직임 중 연결 유지, 머리와의 일관성은 판단할 수 없다.

이 비교판은 세 정지 프레임의 크기 및 실루엣을 검토하기 위한 자료다. 사람의 시각 승인을 기록하지 않았으며 달리기 사이클, 전환, 접촉 타이밍이나 본편 통합을 승인하지 않는다. 검토자 승인 전까지 두 safe 파일은 격리 후보로 유지한다.
