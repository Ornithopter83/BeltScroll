# M6K 보행·기본 공격 전환 리뷰 게이트

## 구현 범위

`player_visual_animator.gd`의 임시 보행 동작은 이동 거리로 위상을 전진시켜 좌우 교대 리듬을 만들고, 속도에 따라 상체 기울기·반동과 접지 압축·상하 리듬을 조절합니다. 현재는 전신 정지 원화에 적용하는 변환이므로 다리와 팔을 별도로 관절화하거나 실제 좌우 발 접촉 포즈를 그리지는 않습니다. 따라서 시각적으로 완성된 좌우 보폭으로 판정할 수 없으며, 절차형 임시 움직임으로만 표시합니다. 알파 발점을 매 프레임 유지하므로 Player 물리 위치와 실제 히트박스에는 영향을 주지 않습니다. 공격 준비와 후딜은 이동 중일 때 보행 위상을 각각 걷어내고 다시 섞으며, 접촉 동작은 기존 공격 타이머와 콤보 단계를 따릅니다.

PlayerArt와 PoseBlender는 공통 알파 발점을 맞춘 채 105ms 완화 알파 블렌드를 합니다. 전환 동안 두 표시 계층이 함께 렌더되며, 공격이 끝나면 PoseBlender를 즉시 안전 대기 그림으로 덮어쓰지 않고 현재 포즈를 페이드 아웃합니다. 애니메이션 우선순위는 KO, 피격, 스킬, 공격, 점프/착지, 방향 전환, 보행/대기 순서로 유지합니다.

## 원화 승인 경계와 부족분

현재 등록된 걷기/달리기 프레임이 없으므로 보행 위상, 상체 반동, 압축 리듬만 기존 정지 원화에 적용합니다. 이 변환은 승인 프레임으로 보고하지 않습니다. 실제 좌우 다리 보폭, 발 들기/착지, 팔 반대 흔들기를 보여 주는 원화 걷기 시퀀스는 별도 제작·검토가 필요하며 보행 원화 완성 조건은 차단 상태입니다.

공격 접촉은 기존 승인 키포즈 등록과 실제 공격 phase 타이머를 사용합니다. 임시 변환과 계층 알파 전환도 원화 프레임 승인을 의미하지 않습니다. 렌더링 결과의 최종 시각 승인은 별도 리뷰 대상입니다.

## 확인 항목

2026-10-10 검수에서 `tests/m6k_walk_attack_blend_smoke.gd`가 PASS했습니다. 검사는 PlayerArt와 실제 표시 중인 PoseBlender 스프라이트 각각의 알파 발점을 측정하도록 보강했고, 보행, 공격 접촉, 공격→보행 인계에서 모든 보이는 원화의 발점 오차가 0.08px 이내인지 확인합니다. 콤보 방향 반전, 피격·KO 우선순위, 대기 복귀도 PASS했습니다. 이 자동 위치 검사는 실제 보행 실루엣 승인으로 간주하지 않습니다.

`assets/art/player/elven_fighter_walk_opposite_stride_v1_candidate_1254x1254.png`는 현재 격리 F6 비교 카드에 추가 후보로만 노출합니다. 파일명에 `resource`가 들어간 RESOURCE 후보는 발견되지 않아 누락 카드는 유지됩니다. 추가 후보도 본편 manifest·allowlist·Player 씬에 등록되지 않았으며 사람 승인 대기 상태입니다.
