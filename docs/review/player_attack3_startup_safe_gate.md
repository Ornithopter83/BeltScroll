# 3타 startup safe 후보 검수 기록

## 상태

원본 `assets/art/player/elven_fighter_attack3_startup_v1_candidate_1254x1254.png`를 유지하고 별도 safe 후보를 만들었습니다. 기존 #49 게이트와 원본 파일은 수정하지 않았으며, 후보를 Player·애니메이션·런타임 리소스에 연결하지 않았습니다. 기계 검사는 통과했고 사람의 시각 승인과 게임 연결은 대기 중입니다.

## 원본 보존과 정규화

- 입력 및 출력은 1254×1254 RGBA8 PNG입니다.
- 원본 SHA-256: `970ecbeefd531b650a25197a9dcba92fb7affd1593f8f399efc8c7626e50d05e`.
- 원본의 비영점 alpha 경계 여백은 좌/상/우/하 **0/19/10/17px**였고 왼쪽 캔버스 경계에 alpha가 있어 외곽 투명 조건을 만족하지 못했습니다.
- 축소 전 8방향 이웃이 없는 alpha 픽셀 415개를 제거했습니다. 남은 전체 실루엣 경계는 `(2, 21)`에서 시작하는 1242×1185px입니다. 이 상자 전체에 균일 비율 `0.845411`을 적용해 1050×1002px로 축소하고 캔버스 중앙 `(102, 126)`에 배치했습니다. 잘라내거나 그려 넣지 않았습니다.
- premultiplied-alpha 처리로 RGB를 alpha에 곱한 뒤 Lanczos 축소를 적용하고, 축소 후 RGB를 alpha로 나눠 되돌렸습니다. alpha 0 픽셀의 RGB는 0으로 정리했습니다. 축소 과정에서 새로 생긴 고립 alpha 픽셀 146개도 제거했습니다.
- 결과 경계 여백은 좌/상/우/하 **102/126/102/126px**입니다. 모든 외곽 픽셀은 완전 투명하고, 출력에서 고립 alpha 픽셀은 0개입니다.
- Smoke의 alpha 5% 영역 점유는 얼굴 69,026→49,385px, 가드 주먹/팔 91,752→65,683px, 전방 주먹/팔 34,378→24,417px, 왼쪽 다리/부츠 81,495→58,324px, 오른쪽 다리/부츠 97,406→69,631px였습니다. 각 영역의 alpha가 남았는지 확인한 수치이며 시각 승인 판정은 아닙니다.

## 발 기준점과 3배 비교판

`assets/art/review/player_attack3_startup_safe_comparison.png`는 요청된 순서로 576×576px(192px 게임 표시 높이의 3배) 패널을 배치합니다. 캔버스 크기는 2256×760px이며 각 패널은 동일한 1254px 캔버스 전체를 균일 축소해 표시합니다. 노란 십자 표시는 alpha 5% 이상에서 가장 낮은 픽셀 행의 연속 구간 중심입니다.

| 포즈 | 발 기준점 (1254px 원본 캔버스 좌표) |
|---|---:|
| 2타 접촉 v6 safe | (1099, 1143) |
| 3타 startup safe | (458, 1122) |
| 3타 접촉 v2 | (273, 1145) |

비교 포즈 간 기준점 차이는 startup−2타 `(-641, -21)px`, 3타 접촉−startup `(-185, +23)px`입니다. 포즈 사이의 발 선택이 같다고 가정하지 않도록 각 패널의 표시점을 그대로 기록했습니다.

정규화에 따른 startup의 alpha 5% 발 기준점은 원본 `(423, 1199)`에서 safe `(458, 1122)`로 이동해 **(+35, -77)px** 변했습니다. 192px 게임 표시 크기로 환산하면 약 **(+5.4, -11.8)px**입니다. 이 이동은 동일한 원화를 안전 여백 안에 중앙 배치한 결과이며 발 위치의 시각 승인이나 엔진 anchor 변경을 의미하지 않습니다.

## 승인 체크

| 확인 항목 | 상태 |
|---|---|
| 1254×1254 RGBA8 및 네 방향 90px alpha 여백 | 통과: 102/126/102/126px |
| 완전 투명 외곽 및 고립 픽셀 제거 | 통과: 외곽 alpha 0, 고립 alpha 0 |
| 균일 축소 및 premultiplied-alpha 처리 | 스크립트/Smoke 확인 |
| 얼굴·양팔·양다리 alpha 영역 보존 | Smoke 확인; 시각 검수 대기 |
| 원본 PNG 바이트 보존 | 준비 스크립트 실행 중 바이트 비교 통과; SHA-256 기록 |
| 사람의 시각 검수 및 최종 승인 | 대기 |
| 게임 리소스 연결 | 사람 승인 전 금지; 미연결 |

## 재현
