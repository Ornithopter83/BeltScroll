# M6M 보행 연속성 후보 게이트

## 실행

Godot 에디터에서 `scenes/review/m6m_walk_sequence_lab.tscn`을 열고 **F6**으로 실행한다. Space는 자동 재생/정지, ←/→는 정지 후 한 장 이동, 1/2/3은 개별 그림 선택, R은 초기화다. 두 비교 패널은 같은 그림을 동시에 보여 준다. A는 캐릭터 루트가 고정되고 B는 초당 48 화면 픽셀 전진한다.

각 원화 PNG는 독립 프레임이다. 잘라낸 스프라이트시트, 수평 뒤집기, 재사용 프레임은 만들지 않는다. 투명 픽셀 경계를 읽어 알파 발끝을 같은 바닥선에 맞춘다. 표시 크기는 원본 1254px 캔버스를 192px로 축소한 값이며, 원본 비율은 유지한다. 각 프레임의 표시 시간은 0.24초, 0.18초, 0.20초다.

## 프레임 판독표

|순서|원화|시간|접지발|들린 발|골반|팔 위상|판독|
|---:|---|---:|---|---|---|---|---|
|1|`elven_fighter_walk_opposite_stride_v1_candidate_1254x1254.png`|0.24초|왼발(추정)|오른발 전진 스윙|중립, 보행 높이|왼팔 뒤 / 오른팔 앞|긴 보폭 후보|
|2|`elven_fighter_walk_passing_v1_candidate_1254x1254.png`|0.18초|왼발(추정)|오른발 발끝 들림|중립, 통과 높이|왼팔 뒤 / 오른팔 앞|통과 포즈 후보|
|3|`elven_fighter_run_stride_v1_candidate_1254x1254.png`|0.20초|**MISSING** · 양발 공중|양발|높음, 도약|왼팔 뒤 / 오른팔 앞|보행 접지로 세지 않는 달리기형 도약|

접지발·관절은 완성 원화의 실루엣에서 읽은 검토용 추정치이며 원화 메타데이터가 아니다. 1→2 프레임은 같은 왼발 접지라고 가정한 수동 발 위치 표식(-17px→-10px, 원본 캔버스 좌표 기준)을 사용한다. 3번은 지지발이 없으므로 접지 슬립 계산에서 제외한다.

## 계측 정의와 현재 기대 결과

- **제자리 접지 잔차**: 같은 왼발 접지로 표기한 두 프레임의 발 위치 차이. Godot 4.7.2 런타임 계측에서 **1.07px/frame**.
- **이동 접지 잔차**: 위 발 위치 차이와 B 패널의 실제 루트 이동량(48px/s × 0.18s)을 합산한 값. Godot 4.7.2 런타임 계측에서 **9.71px/frame**. 고정 발 자국을 따라가는 보정값이 아니므로 이동 패널의 잔차가 큰 것은 이 후보가 실제 보행 접지를 아직 설명하지 못한다는 표시다.
- **실루엣 점프**: 바닥선에 정렬한 두 원본 알파 경계 상단의 수직 차이(192px 캔버스 기준). 이는 화면 판독용 경계 이동이며 관절 추적이나 영상 광류 측정은 아니다. 현재 opposite-stride→passing 알파 상단 차이는 **2.60px**로 계측됐다.
- 이동 루트는 시간에 따라 계속 전진하고 320px 범위에서 패널 안 표시 위치만 순환한다. 원화 순환 순간의 접지 상실은 위상 데이터 부재로 별도 경고한다.

Godot 4.7.2 headless 장면 런타임에서 원화 3/3을 읽고 UI/프레임 갱신 경로가 실행됨을 확인했다. F6 편집기 창의 시각 QA는 수행하지 않았다. 수치는 후보 선별용 수동 표식 기반 계측이다. 정밀 접지 검증 전에는 해당 원화에 키포인트/관절 메타데이터가 필요하다. 표시 시간도 시각 검토용 cadence이며 원화에서 추출한 권위 타이밍이 아니다.

## 게이트 판정

**보행 시퀀스 승인 보류.** 세 그림을 각기 다른 프레임으로 재생해 연속성 후보를 비교할 수 있지만, 왼발 지지 두 포즈만 있고 오른발 지지 접촉이 없다. 좌우 교대, 이중 지지, 접지 상태의 발 고정, 일정한 보폭을 입증할 수 없다. `run_stride_v1`은 공중 달리기 자세이므로 접지 프레임으로 반복해 끼우지 않는다. 필요한 위상은 **MISSING**으로 남긴다.

원화는 기존 미승인 후보 폴더에서 읽기만 한다. 이 검토 장면은 본편 Player, manifest, allowlist에 연결되지 않으며 원화 승인/승격을 하지 않는다.
