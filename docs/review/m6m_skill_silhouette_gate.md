# M6M Num4 / Num5 실루엣 블라인드 비교 게이트

## 목적과 범위

기존 M6L F6 실험장을 동일한 1920×1080 화면 크기로 유지하면서 실제 Player의 몸동작만 분리 관찰한다. 이 비교는 승인 원화의 채택을 결정하거나 자동 PASS를 내리지 않는다. 아래 후보 원화는 계속 참고 패널 전용이며 본편 플레이어나 애니메이션에 연결하지 않는다.

Num5에 대해 기존 실제 화면 계측으로 기록된 최대 PlayerArt 회전은 **0.55752rad(약 0.56rad)**다. 원형 VFX 또는 원형 Skill2Hitbox는 전신 회전 증거가 아니다. 몸통 방향 표시와 PlayerArt의 실제 회전을 관찰하고, 원형 이펙트를 숨긴 상태에서 몸이 도는지 따로 판단한다.

## 조작

| 키 | 동작 |
| --- | --- |
| `4` / 키패드 `4` | Num4 준비→활성→회복 재생 |
| `5` / 키패드 `5` | Num5 준비→활성→회복 재생 |
| `Space` | 두 기술 동시 재생 |
| `P` | 재생 일시정지 / 재개 |
| `R` | 두 Player, 위치, 쿨다운과 중단 상태 초기화 |
| `X` | 기술 취소 |
| `H` / `K` | 양쪽 피격 / KO 검증 |
| `E` | 기술 VFX 표시 / 숨김 |
| `N` | 기술명·기술 설명·후보 캡션 표시 / 숨김 |
| `B` | 실제 판정 외곽선 표시 / 숨김 (판정 동작 자체는 유지) |
| `1` | 시작점-현재점 및 돌진 거리 표시 / 숨김 |
| `2` | PlayerArt 몸통 방향 축 표시 / 숨김 |
| `3` | 주먹 이동 참고선 표시 / 숨김 |
| `0` | 발 기준선·회전축 표식 표시 / 숨김 |

## 권장 블라인드 절차

1. `R`로 초기화하고 `E`, `N`, `B`를 눌러 효과, 기술명, 판정 윤곽을 숨긴다. 1–4 안내 표식은 각각 독립적으로 가릴 수 있다.
2. Num4와 Num5를 각각 여러 번 재생하고 `P`로 준비, 활성, 회복 각 구간을 정지 관찰한다. `R`로 매 시도를 같은 시작점에서 반복한다. Space 동시 재생은 나란히 비교할 때 사용한다.
3. 실루엣만 보고 아래 평가표에 Num4/Num5 식별, 돌진 거리, 몸통 방향, 주먹 경로, 지지발·회전축, 준비·활성·회복 가독성을 기록한다. 안내선을 켠 관찰은 블라인드 실루엣 평가와 구분한다.
4. 이후 `E` 또는 `B`를 하나씩 켜서 원형 VFX와 실제 원형 판정의 위치를 확인한다. 이를 몸의 회전 여부 판정에 대신 사용하지 않는다.

## 판정 기준과 검수 기록

실루엣만으로 Num4의 직선 전진 동작과 Num5의 제자리 회전 동작을 일관되게 구별하지 못하면 **FAIL**이다. 아직 블라인드 관찰 기록이 없으면 **UNVERIFIED**로 남긴다. 추측이나 원형 VFX만으로 PASS 처리하지 않는다. PASS 후보가 되려면 반복 정지 관찰에서 준비·활성·회복이 읽히고, Num4의 전진과 직선 주먹 경로, Num5의 몸통 방향 변화 및 고정된 회전축이 각자 확인되어야 한다.

| 항목 | 기록 |
| --- | --- |
| 화면 크기 / 검수자 / 날짜 | 1920×1080 / 미기록 |
| 이펙트·기술명·판정 외곽선 없는 실루엣 식별 | UNVERIFIED — 수동 관찰 미기록 |
| Num4 돌진 거리 및 직선 주먹 경로 | UNVERIFIED — 수동 관찰 미기록 |
| Num5 몸통 방향 및 고정 지지축 | UNVERIFIED — 최대 약 0.56rad 계측은 참고값이며 블라인드 판정 아님 |
| 준비·활성·회복 반복 정지 관찰 | UNVERIFIED — 수동 관찰 미기록 |
| 최종 판정 | **UNVERIFIED** — 승인 후보 원화를 본편에 연결하지 않음 |

자동 확인 스크립트: `tests/m6m_skill_silhouette_blind_smoke.gd`. 이 문서의 UNVERIFIED 표시는 수동 블라인드 검수 기록이 없는 현재 판정이며 smoke 결과를 PASS로 간주하지 않는다.
