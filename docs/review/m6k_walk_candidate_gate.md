# M6K 보폭 후보 시각 검토 게이트

## 실행

Godot 에디터에서 `scenes/review/m6k_walk_cycle_preview.tscn`을 열고 **F6**로 실행한다. 한 화면의 각 카드는 기존 `run_stride v1`부터 `v5`까지와 탐색된 추가 보폭 PNG를 정지 상태로 보여 준다. 좌우 화살표로 선택 카드를 바꾼다. 원화의 투명 여백을 제외한 알파 경계 높이를 실제 게임 표시 기준 **192px**로 맞추고, 하단 알파 중심과 공통 바닥선을 참고로 표시한다.

## 검토 항목

- 좌우 발의 접지 순서가 교대로 바뀌는가?
- 지지 구간에서 지지발이 화면상 미끄러지지 않는 구성이 가능한가?
- 팔이 다리와 반대 위상으로 흔들리는가?
- 골반 높이가 자연스럽고 좌우 포즈 간 급격히 튀지 않는가?
- 실제 192px 크기에서도 발과 팔의 실루엣이 읽히는가?
- 같은 보폭 원화를 두 프레임으로 반복한 가짜 주기가 아닌가?

이 씬은 원화를 한 장씩 정지 비교하며 자동 재생, 보간, 미러링을 하지 않는다. 후보 이미지 파일만으로 실제 접지 이동이나 지지발 고정을 증명할 수 없으므로, 서로 다른 접지 포즈의 의도와 발 위치를 사람이 확인해야 한다. 동일 보폭 이미지를 번갈아 노출하는 가짜 주기는 만들지 않는다.

추가 보폭 후보는 `assets/art/player` 아래 파일명에 `walk` 또는 `run`과 `stride`가 들어간 PNG에서 기존 v1~v5를 제외해 탐색한다. 파일명에 `resource`가 포함된 항목은 RESOURCE로 표시한다. 현재 `elven_fighter_walk_opposite_stride_v1_candidate_1254x1254.png`는 별도의 미승인 추가 후보 카드에 나타나며, RESOURCE 후보가 없을 때도 **RESOURCE 미도착** 카드는 유지된다. 후보는 이 검수 장면에서만 읽고 본편에 등록하지 않는다.

## 격리 및 승인 상태

미리보기와 후보는 검토용 격리 상태다. 본편 manifest, reviewed allowlist 또는 Player 씬에 자동 등록하지 않는다. 이 작업은 원화 승인이나 본편 반영을 수행하지 않는다. **사람의 시각 승인 대기** 상태이며, 승인 기록은 별도 검토 절차에서 남긴다.
