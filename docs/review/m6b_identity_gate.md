# M6B 캐릭터 정체성 검수 게이트

## 상태

**미승인 후보 — 본편 승격 금지.** 기존 v8은 현재 `PlayerArt`이며, 새 다크 판타지 리디자인은 검수용 비교만을 위해 정규화했다. 이 작업은 본편 `PlayerArt`, manifest, allowlist를 수정하거나 후보를 승인하지 않는다.

## 산출물

- 원본 입력: `assets/art/player/elven_fighter_dark_fantasy_redesign_v1_candidate_1254x1254.png`
- 정규화 사본: `assets/art/player/elven_fighter_dark_fantasy_redesign_v1_safe_candidate_1254x1254.png`
- 현행 v8 대조: `assets/art/player/elven_fighter_reference_v8_clean_candidate_1254x1254.png`
- Window 비교판: [m6b_redesign_candidate_comparison.png](../../assets/art/review/m6b_redesign_candidate_comparison.png)
- 생성기: `tools/prepare_m6b_redesign_candidate.gd`

프로젝트 루트에서 `godot --path . --script res://tools/prepare_m6b_redesign_candidate.gd -- --window`을 실행하면 1920×1080 비교 Window가 열린 채 유지된다. 창의 CLOSE 버튼 또는 제목 표시줄 닫기로 종료할 수 있다. `--window`를 빼면 후보와 정적 비교판을 만들고 종료한다.

## 정규화 기록

입력 이미지의 알파 실루엣은 1254×1254 캔버스에서 `(0, 0)`부터 `(1231, 1253)`까지 닿아 좌측·상단·하단 여백이 없었다. 입력 파일은 바이트 단위로 보존했다. 실루엣 알파 경계를 자르지 않고 원 비율대로 축소한 뒤 투명한 RGBA 캔버스에 배치했다.

| 항목 | v8 현행 | 다크 판타지 후보 |
|---|---:|---:|
| 캔버스 | 1254×1254 | 1254×1254 |
| 정규화 후 알파 경계 | `(110, 90)`, 1034×1074 | `(99, 90)`, 1055×1074 |
| 알파 경계 여백 L/T/R/B | 110/90/110/90 px | 99/90/100/90 px |
| 게임 표시 높이 | 576 px | 576 px |
| 표시 기준 | Sprite scale 0.4469274 × Camera zoom 1.2 | 동일 |

새 후보의 아래쪽 알파 경계는 y=1164로 맞춰 v8과 같은 발 기준선을 사용한다. 투명 여백을 만들기 위해 원화를 자르거나 본편 아트를 교체하지 않았다.

## 시각 검수 기록

- **얼굴·정체성:** 두 그림 모두 뾰족한 귀, 오른쪽을 향한 시선, 여성 엘프 전사, 갈색 포니테일과 전투 자세를 공유한다. v8은 눈이 크고 표정이 부드러운 스타일이며, 후보는 더 사실적인 측면 얼굴과 진한 눈매·진지한 표정이다. 후보의 길게 땋은 머리는 v8의 넓게 흩날리는 포니테일과 형태가 분명히 다르다.
- **복장:** v8은 민소매 청록색 랩 상의와 넓은 청록 바지 중심의 경량 격투가 복장이다. 후보는 어두운 가죽·금속 어깨 갑주, 검은 상의, 금색 문양의 긴 비대칭 튜닉과 보호 장구를 더해 복장이 더 무겁고 장식적이다. 청록·금색 팔레트와 엘프 전사 인상은 이어지지만 복장 실루엣과 재질 표현의 차이가 크다.
- **팔다리 식별성:** 576px 게임 표시 높이에서 두 주먹과 양팔, 양쪽 다리 및 부츠가 배경과 구별된다. 후보는 상체 갑주·팔 보호대와 튜닉 장식의 세부가 많아 중앙 몸통과 겹친 팔의 내부 경계가 v8보다 복잡하다. 무릎 아래 두 부츠와 벌어진 다리 방향은 분리되어 읽힌다.
- **잘림·anchor:** 정규화 후 후보는 네 가장자리에서 최소 90px 투명 여백을 유지한다. 발끝과 땋은 머리 끝, 양 주먹은 캔버스 밖으로 잘리지 않았고, 비교판의 두 캐릭터 발은 공통 기준선에 놓인다. 입력본은 가장자리에 붙어 있었으나 정규화 사본에서 여백을 확보했다.

## 결정

후보는 원본 정체성의 공통 표식(엘프 귀, 갈색 머리, 전투 자세)은 유지하면서 얼굴 표현과 복장 설계를 상당히 바꾼 리디자인이다. 게임 크기에서 기본 팔다리와 발 anchor는 식별 가능하고 캔버스 잘림도 해결됐다. 다만 복장 내부의 높은 명암·장식 밀도와 기존 v8 대비 얼굴 스타일 변화는 승인자가 최종 검토해야 한다. 이 문서는 시각 검수 기록이며 후보 승인 또는 본편 반영을 뜻하지 않는다.
