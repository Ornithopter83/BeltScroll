# M6V GRID 64 신체 변형 품질 게이트

## 구현 요약

`player_body_mesh.gd`의 GRID 64 변형을 관절 중심 회전과 부드러운 캡슐형 영향 영역으로 정리했다. 보행에서는 한쪽 발을 지지발로 고정하고 반대쪽 다리의 고관절·무릎을 굽히며, 골반 바운스와 어깨·팔의 역위상 움직임, 머리 회전과 포니테일 지연을 더했다. 기존 지지발 전환 보정은 발목 아래에서만 점진적으로 적용한다.

공격 1~3타는 어깨·팔꿈치 회전과 작은 상체 체중 이동을 단계별로 분리했다. Num4/5도 동일한 GRID 64 경로에서 완만한 캡슐 가중치를 사용한다. 급격한 회전이 래스터 셀을 접거나 뒤집는 경우를 줄이기 위해 관절 회전량을 제한했다. `sample_rendered_point`, 접촉점 계산 경로와 지지발 getter의 함수·좌표 계약은 유지했다. 텍스처 UV 배열은 변형하지 않는다.

## 검증 결과

`godot.exe --path . --script res://tests/m6v_body_deformation_quality_window_smoke.gd`를 실제 Window renderer(OpenGL 3.3, AMD Radeon RX 6900 XT)로 실행했고, headless 실행도 통과했다.

- 15fps 보행 샘플에서 네 보행 위상을 모두 관측했다. 골반 변위 범위는 10.82 원본 픽셀, 팔 끝점 최대 이동은 21.34픽셀, 머리·포니테일 끝점 최대 이동은 26.91픽셀이다.
- 같은 보행 시각을 15fps와 60fps에서 비교했을 때 샘플 좌표 차이는 0.0000 원본 픽셀이다. 보행 매핑은 프레임 간 누적 오차 없이 위상으로 결정된다.
- 공격 1~3타의 준비·활성·회복 포즈에서 GRID 삼각형 방향 뒤집힘이 없었다. 최소 면적은 206.087 제곱 원본 픽셀, 최대 인접 정점 간격은 38.57 원본 픽셀이다.
- Num4/5 단계의 최소 셀 면적은 132.557 제곱 원본 픽셀, 최대 인접 정점 간격은 43.68 원본 픽셀이다. 두 값 모두 변형 전 셀 면적 약 383.7과 변형 전 변 간격 약 19.6보다 양수이며, 셀 접힘이나 비정상적인 한 셀 급증은 검출되지 않았다.
- 1280×720 viewport와 플레이어 아트 배율 0.4469274에서 Window 렌더 경로를 확인했다. 최대 변 간격은 표시상 약 17.2픽셀(원본 좌표 × 0.4469274)이다.
- 모든 65×65 UV 정점이 원본 텍스처 좌표와 일치했다. 양쪽 지지발 getter 잔차는 최대 0.0001픽셀이다.

검사 출력은 `M6V_BODY_QUALITY|fail=0|fps=15,60|display=1280x720@0.447|fold_min=206.087|edge_max=38.57`이다. 실행 환경에서 로그 파일 생성과 시스템 인증서 읽기 오류가 출력됐지만, 두 실행 모두 종료 코드 0으로 검사를 완료했다.

## 화면 자연스러움 판정 기준

축소 표시에서 보행 시 발은 지면에 고정되고 반대 다리는 고관절에서 들리며, 상체·팔·머리카락은 작은 범위로 후행해야 한다. 공격 포즈는 어깨와 팔꿈치가 분리되어 움직이되 상체가 팔보다 크게 비틀리지 않아야 한다. 이 게이트는 실제 Window renderer에서 위상별 움직임, 삼각형 방향, 셀 간격, UV 정합을 측정해 연속성과 자연스러움의 기하 대리 지표를 통과했다.

알파 외곽선, 관절의 픽셀 틈, 프레임 간 스크린샷 차분은 자동으로 측정하지 않는다. 이 항목은 화면 캡처 비교를 추가하기 전까지 육안 검토 대상이다.
