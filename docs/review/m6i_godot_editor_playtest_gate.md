# M6I Godot 에디터 전투 연습장 게이트

## 실행

1. Godot 4.7.2에서 프로젝트를 엽니다.
2. `scenes/review/m6i_combat_test_arena.tscn`을 열어 활성 씬으로 둡니다.
3. **F6 (현재 씬 실행)** 을 눌러 연습장을 엽니다. 이 씬은 메인 게임 세션이나 추가 전투 런타임 설정에 의존하지 않습니다.
4. 창에 포커스를 둔 채 조작합니다. **WASD** 이동, **J** 기본 공격, **Num4** 돌진, **Num5** 회전입니다. 숫자열 4/5가 아니라 키패드 Num4/Num5 입력을 확인합니다.
5. 레이더가 추적해 공격할 때 맞아 플레이어 HP, 넉백, 경직 잔여 시간이 변하는지 확인합니다. **R**은 씬을 다시 불러와 기본 상태로 재시작합니다.

## 수동 확인 게이트

- HUD의 기본 공격 단계와 준비/공격 판정/후딜이 입력에 맞춰 변한다.
- Num4와 Num5의 스킬 phase와 개별 쿨다운이 실제 Player 런타임 값에 따라 변한다.
- 공격 판정이 실제 Raider에 닿으면 Raider HP가 감소하고 피격 반응이 나타난다. 공격이 빗나가면 HP는 그대로다.
- 실제 Raider의 공격을 맞으면 Player HP, 넉백, 경직 잔여 시간이 바뀌며 경직 중 이동/공격 입력이 제한된다.
- HP와 전투 상태는 연습장 UI가 대입하지 않는다. 씬 재시작은 실제 Player/Raider를 다시 인스턴스화한다.

## 자동 구조 스모크

`tests/m6i_combat_test_arena_window_smoke.gd`는 연습장 씬의 로드, 기존 Player/Raider 씬 인스턴스, 기존 Hitbox/AttackArea/ReceiveArea, HUD 항목, Num4/Num5 바인딩과 별도 저장 override 적용을 확인합니다. 실제 창에서의 입력 타이밍과 시각적 판정은 Godot 에디터에서 F6로 수동 확인합니다.
