# M6R 공격 접촉점 시각 검수 게이트

## 목적과 실행

이 장면은 본편에서 분리된 Player 공격 접촉점 검수장이다. Godot 편집기에서 `scenes/review/m6r_strike_contact_lab.tscn`을 열고 **F6**로 현재 씬만 실행한다. 프로젝트 메인 씬, Player 원화 승인 상태, 애니메이션 등록 데이터는 수정하지 않는다.

## 조작

- 좌우 화살표: 기본 1·2·3타, Num4 돌진, Num5 회전 선택
- 위아래 화살표: startup / active / recovery 선택 및 정지
- Space: 선택된 단계 반복 재생/정지, `L`: 단계 경계 반복 켜기/끄기
- `.` / `,`: 1/60초씩 앞/뒤로 이동
- `F`: 좌우 반전, `C`: 카메라 오프셋 전환, `R`: 위치/카메라 초기화
- 화면에서 현재 표시된 실제 Sprite의 주먹 끝을 클릭: 선택 기술·단계·텍스처 프레임에 사람 확인 좌표를 기록
- `T`: 손 좌표가 확인되면 주먹-판정 오차 측정. 좌표가 없어도 실제 ReceiveArea 교차와 phase별 monitoring ON/OFF는 별도로 측정
- `G`: 적 ReceiveArea를 주먹 밖 150 px에 배치. `T`는 현재 monitoring 상태와 실제 ReceiveArea 교차 결과를 계측
- F10: 프로젝트의 실제 충돌 윤곽 표시/숨김. 핑크 십자/윤곽은 공격 Shape, 청록 원/윤곽은 실제 적 ReceiveArea, 노란 다이아몬드는 사람 확인 손끝이다.
- Backspace: 세션 내 사람이 지정한 손 좌표 초기화

## 좌표와 판정 기준

노란 기준점은 AttackFlash/VFX 좌표에서 만들지 않는다. 현재 화면에 렌더링된 Sprite를 클릭해 해당 텍스처의 원화 픽셀 좌표를 기록하고, Sprite의 현재 전역 변환·좌우 반전·카메라를 통해 월드 좌표로 계산한다. 표시 텍스처가 바뀌면 이전 기준점은 사용하지 않는다. 좌표가 없거나 현재 프레임과 텍스처가 다르면 `UNVERIFIED`다.

오차는 손 기준점과 선택된 실제 CollisionShape2D의 전역 중심 사이 거리(world px)다. 24 px 이하만 자동 기하 측정 PASS로 표시한다. 자동 오차는 사람이 손 위치를 확인했다는 뜻이 아니므로 별도 줄에 provenance를 표시한다. 원화 픽셀에 손끝을 직접 지정하지 않은 기술/단계는 승인이나 PASS로 해석하지 않는다. 주먹 밖 검사는 별도 적중/비적중 관찰을 기록하고, active 전후 monitoring이 꺼져 있는지 F10 윤곽과 계측 상태를 함께 확인한다.

## 검수 기록

현재 저장소 기준: 사람 확인 좌표 0/15, 기본 공격 3개와 Num4/Num5의 startup·active·recovery 모두 `UNVERIFIED`. 원화에 직접 찍은 손끝 좌표가 없으며 이 WORKITEM은 검수장 도구만 추가한다. 사람이 각 표시 프레임에 기준점을 지정한 뒤 손-판정 오차, 주먹 밖 적중, 접촉 전후 비활성, 좌우 반전, 카메라 이동을 기록하고 재검수한다. 이 게이트는 본편 아트 승인 상태를 변경하지 않는다.
